OSUAGWU SOLOMON TOPRATED — PHRASLY ADMIN COOKIE EXPORTER
Version 1.0.0

INSTALL
1. Extract this ZIP into a folder you will keep.
2. Open chrome://extensions (or edge://extensions).
3. Turn on Developer mode, choose Load unpacked, and select the folder containing manifest.json.
4. Pin Osuagwu Solomon TopRated if desired.

COPY
Sign in to your Phrasly account at https://phrasly.ai, open this extension, and click Copy Cookies as JSON.
The complete JSON array can be pasted into the Phrasly account-session field at https://topratedseotools.com/admin/phrasly.

SEND TO TOPRATED
1. On the signed-in phrasly.ai tab, open the extension and click Send to TopRated Admin.
2. Sign in with your TopRated account owner credentials if needed.
3. Choose the Phrasly account to update. Its existing label, capacity and enabled setting are retained.
4. Click Save imported account session. Wait for Account session updated.

The receiving Admin page must be opened by the extension in the same browser/profile.
The handoff is single use and expires after five minutes. If it expires, return to Phrasly and send again.
Cookie values are held in browser-session memory during handoff and are not put in a URL, logs or synced storage.
The server checks Admin authorization and saves the account session encrypted.

This is the Admin exporter. Writers continue to use the separate TopRated Phrasly Access extension to launch Phrasly.
Adapted for the user's requested workflow from the supplied Jawad Ahmed EXR view/copy extension.
