# Retired native Claude extension experiment

The owner requires the same dedicated subdomain proxy as Grammarly and
StealthWriter, with no writer extension. The pilot is retired as of 13 November
2026. The old issuance functions reject requests and redemption returns HTTP
410 without returning cookies. The public ZIP and install UI are removed.
Historical source and database records are retained for audit purposes.

The previous browser test established that the saved account session worked on
the native Claude site. It did not verify `claude.topratedseotools.com`.
See [Claude OneClick setup](claude-oneclick.md) for the actual proxy status.
