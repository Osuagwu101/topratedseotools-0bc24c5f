# Clickable customer tool summary

The Active / expired card on /admin/customers/:userId now leads directly to Assigned tools & subscriptions. It includes a visible View tools & revoke access hint and supports keyboard Enter. The list receives focus and a scroll offset below the Admin header. Existing Cancel actions are labelled Revoke access; each retains its existing authenticated server action, selected order ID, confirmation and customer-query refresh. The existing backend eligibility remains Admin-assigned offline subscriptions; online payments are not given a new cancellation flow by this UI change. Payment history and permissions are unchanged.

The native customer route contains the same interaction. Because the main Admin app is currently deployed separately, a scoped bridge supplies the change to the existing page without replacing its compiled modules. It runs only on a customer detail route and preserves the original React handlers. It does not add an API or perform database writes during deployment.

Validation: customer route TSX compilation, seven Chromium fixture checks, and seven checks using the deployed bridge against synthetic customer data. Verified click/keyboard focus, selected-tool handler preservation, reactive counts, navigation, no duplicate hints and no changes on other Admin routes. No real customer was revoked during testing.
