Cookie-Based Tools

Cookie-based tools (the browser-extension model, not the reverse-proxy engine Stealth Writer uses — see phrasly-oneclick-postmortem.md for why). Paste the real site's URL and an exported cookie JSON array (the usual chrome.cookies.getAll export shape: domain, name, value, path, secure, httpOnly, expirationDate, sameSite) per account. Same capacity pooling as the Tool Vault — blank is unlimited reuse, a number caps how many buyers share that one account before the next one takes over. Add a second account under the same tool to attach a second real account/server.
